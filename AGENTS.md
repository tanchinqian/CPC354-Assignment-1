# Scope and ownership

This repository deliberately starts as a skeleton. Implement only the module or
task explicitly requested by the human; do not silently complete other members'
work or import the complete prototype from a neighbouring workspace folder.

- Tan Chin Qian: geometry.js.
- Tan Jia Hong: animation.js.
- Yap Han Lim: ui.js, HTML and CSS.
- Goo Yong Shen: renderer.js and main.js integration.

Read docs/INTERFACES.md and docs/REQUIREMENTS.md before changing a module. Treat
the group's current ASSIGNMENT 1.pdf as authoritative over senior references.
Use raw WebGL; no Common library or graphics framework. Preserve informative
function comments describing owner, purpose, parameters, returned data and TODOs.
Ask the human about material uncertainties rather than inventing assignment rules.
Keep AI/external-code disclosures truthful and preserve other members' work.
